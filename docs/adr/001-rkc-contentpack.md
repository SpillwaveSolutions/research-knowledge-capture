# ADR 001 — RKC is a ContentPack

Status: accepted. 2026-08-22.

RKC is Layer 0 of a research second brain. It owns OKF nouns, folders, registered rels, and ingest writes. It does not own vectors, Kuzu, or Article nodes.

`research-graph` (Layer 1) projects validated OKF into Agent Brain. The projector stays there until a second pack needs the same Protocol.
